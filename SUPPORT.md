# Support

## Before asking for help

Check the [README](README.md), [Getting started](docs/tutorials/getting-started.md), [CLI reference](docs/reference/cli.md), [Architecture](docs/explanation/architecture.md), and [Compatibility](docs/compatibility/README.md).

## Usage questions

For reproducible bugs, use the [bug report form](https://github.com/LloydCoder/tinlance-agent-developer/issues/new?template=bug_report.yml).

For feature proposals, use the [feature request form](https://github.com/LloydCoder/tinlance-agent-developer/issues/new?template=feature_request.yml).

For questions that need discussion rather than a tracked bug or feature, use GitHub Discussions if enabled.

## Security

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Maintainer contact

The current project maintainer is **@LloydCoder**.

Include the TADL version, Node.js version, command run, and relevant error output with sensitive data removed.
