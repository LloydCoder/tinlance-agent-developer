## [1.4.0] - 2026-10-06

### Added

- Enterprise hardening and executable developer-boundary security controls.
- CodeQL and secret-scanning workflows.
- CycloneDX SBOM generation and release artifact attestations.
- Expanded TADL CLI validation and inspection commands.
- Ecosystem integration contract validation.

### Security

- Full SHA pinning for GitHub Actions.
- Registry digest binding to artifact payloads.
- Evaluation certification requires every evaluation case to pass.
- Agent publication requires verified signatures.
- Learning proposals cannot change authoritative authority state.
