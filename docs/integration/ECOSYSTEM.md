# Tinlance Ecosystem Integration

TADL is a shared developer plane, not a merger target. Agent OS consumes TADL for lifecycle/orchestration; Agent Platform consumes TADL intent and remains authoritative. Domain products retain their domain semantics and may publish or consume TADL artifacts.

Current consumers/producers include FDSE, FDSE Toolkit, BugFlow, TwinGuard, AI Shield, ThreatFade, ReconOS, TADS, FAS, Hezqara, and FadeReach.
