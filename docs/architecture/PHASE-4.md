# TADL Internal Phase 4 — Governed Capability Contracts


> **Phase namespace:** This is the TADL repository's internal implementation sequence. It is not the ecosystem certification phase with the same number in `docs/ecosystem/PHASE-MATRIX.md`. Ecosystem P0–P10 gates cross repository boundaries and are authoritative for release sequencing.

Capabilities are typed, versioned, risk-classified requests. Effective capability is the intersection of declared capabilities and Platform authorization, with declared approval requirements satisfied. This package never grants authority.
